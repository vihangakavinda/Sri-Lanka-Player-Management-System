SRI LANKA MEN'S CRICKET MANAGEMENT SYSTEM - FRONTEND

Files:
- players.html        Player listing/search page
- player.html         Individual player profile page
- css/style.css       Shared site styling
- js/players.js       Players page logic/API connection
- js/player.js        Player profile logic/API connection

API:
https://script.google.com/macros/s/AKfycbyFh2z7XzHtYcYRPSHY5B4T4v5W2ciycnovExzNKZSAZl8H7dfunMNv0buDJKOU_3Cd/exec

HOW TO RUN
1. Open this folder in VS Code.
2. Use the Live Server extension.
3. Open players.html through Live Server.
4. Click "View Profile" on any player.

Do not open the HTML by double-clicking if your browser blocks network requests from file:// pages.
